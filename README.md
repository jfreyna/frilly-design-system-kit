# The Frilly Design System Kit

Turn any website into a real design system, then explore redesigns of it, in minutes, using Claude or your agent of choice. Made for designers. No coding, no setup, no installs.

## What it does

Give it a website and it extracts the site's actual colors and typography into a complete, professional design system: full tonal palettes using the Material Design framework. Every gray organized into a scale, a documented type hierarchy. Then it can redesign: pick two fonts and a site whose feel you admire, and it shows you the same brand wearing a new system, as a sample
homepage you can open in your browser.

Every value is traceable to something the site actually uses. The kit's core principle is **extract, don't invent**: the system organizes a brand rather than replacing it.

## How to use it (three steps)

1. Open [claude.ai](Claude) or [chatgpt.com](ChatGPT) and start a new chat. The free versions work for this.
2. Copy the ENTIRE document in [https://github.com/jfreyna/frilly-design-system-kit/blob/master/Frilly_Design_System_Kit.md](`Frilly_Design_System_Kit.md`) from this repository and paste it into the chat, 
3. Fill in the three blanks at the top: your website, two fonts (or "keep our current fonts"), and a reference site you admire. Hit Enter to watch it work.

You'll get a spec sheet with your design system formatted in the Material Design convention (`design-system.html`) and a sample homepage (`index.html`). Save both files in one folder and double-click `index.html`.

Run it again with different fonts or a different reference site, give it creative notes, go on random tangents. Each variation takes only minutes, so explore freely.

## For design pros, students, and enthusiasts

This is a working example of a reusable AI "skill": a set of instructions written once, carefully, that anyone can hand to an AI model to get expert results repeatably. Read the document itself after you've run it. Notice that it encodes a method (what to extract, in what priority order, what counts as noise, how to verify before presenting) rather than just a request. That gap, between asking an AI for "a design system" and handing it a method, is the
skill of working this way.
